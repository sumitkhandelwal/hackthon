## 1. What's driving your performance (Success Triangle)

### Clear: What expectations/goals are clear vs unclear?

**Sample Answer**

> **Clear:**
>
> * Deliver assigned tasks on time with good quality.
> * Collaborate effectively with team members.
> * Improve technical skills and contribute to project success.
>
> **Needs more clarity:**
>
> * Long-term project priorities.
> * Success metrics for some activities.
> * Opportunities to take ownership of larger initiatives.

### Capable: What capability, tools, time or resource constraints exist?

**Sample Answer**

> * I have the required technical skills for my current responsibilities.
> * I would benefit from additional training on new technologies and project architecture.
> * Better documentation and knowledge sharing would improve productivity.
> * Occasional dependency on other teams delays task completion.

### Motivated: What's helping/hindering motivation?

**Sample Answer**

> **Helping:**
>
> * Learning new technologies.
> * Solving challenging technical problems.
> * Positive feedback and collaboration.

> **Hindering:**

# 2. Quarterly Plan (Big 5)

This section asks what you will accomplish next quarter.

Example:

> **My Top 5 Priorities**
>
> 1. Deliver all assigned project deliverables on schedule.
> 2. Improve code quality through testing and code reviews.
> 3. Learn one new technology relevant to the project.
> 4. Reduce defects by following best development practices.
> 5. Improve communication with stakeholders.

### How you've protected time for "Big Rocks"

> * Reserve dedicated focus time every morning for high-priority tasks.
> * Plan weekly goals every Monday.
> * Reduce unnecessary meetings where possible.
> * Track progress weekly.
